## 已确认结论（供后续实施直接引用）

1. **当前「丑」的主因是渲染管线 + 地图编排，不是素材量**：约 70% 管线/编排、30% 素材。P0（0 新素材）即可消除 4 类破绽中的 3 类。
2. **现有素材存在系统性帧映射错误**：厨房/卫生间地板误用墙列护墙板切片；4 个墙帧全错（`wall.south` 全透明）；"冰箱"帧实为浴缸；"马桶"帧含两件洁具；门/冰箱帧底部 16px 透明导致悬空；地毯帧宽 40 而实际 34 且 x 偏 1。
3. **素材库选型关键矛盾**：不存在「现代公寓 + 16×16 + 墙体系统完备 + 可随公开仓库分发」的高质量整套素材。
4. **用户已选路线（2026-10-23）**：**LimeZu《Modern Interiors [16X16]》**（观感最好）。授权可商用/可修改、**禁止再分发**、必须署名 → **素材文件不得提交进公开 git 仓库**，落地按 asset-candidates.md §4.2 方案 A：**gitignore + 私有同步 + 缺失时占位渲染并显式告警**；同时可并行向作者申请书面许可（待核实）。
5. **下一步（用户选择：先定素材库，再做风格验证 mock）**：需要先购买并下载 LimeZu 包，再用它 + Memao 角色制作卧室/客厅/厨房/卫生间风格验证 mock，确认 48×48 角色与 16px 家具的比例、以及目标观感，之后才动渲染管线（P0/P1 计划已备好）。
6. **风格备注（2026-10-23 用户反馈）**：现有 mock「少了点公寓的感觉，没有个人房间」——后续场景编排需要体现「个人房间」属性（各房间的功能区分、个人物品/生活痕迹），不能只做成家具陈列 demo。
